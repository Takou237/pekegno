0.2 Avant de commencer (une seule fois)

  • Backend à jour (git pull de corrections) et migrations appliquées : docker exec pekegno-server php artisan migrate.
  • Créer les caisses O / M / B (+ W / V à Abidjan) : docker exec pekegno-server php artisan db:seed --class=TreasuryAccountSeeder. Sans cela, seules les caisses C existent et les scénarios C2 à C4 ne peuvent pas être joués.
  • Vider le cache : docker exec pekegno-server php artisan cache:clear. Frontend lancé (npm run dev dans frontend/), puis Ctrl+Maj+R dans le navigateur.
  • Avec le super-admin, dans Catégories : créer « Canva » et « Matootoo » (« livre » existe déjà), puis un service de catégorie Canva (ex. « Abonnement Canva », 5 000).
  • Garder une fenêtre de navigation privée pour se connecter avec un second compte en parallèle.
